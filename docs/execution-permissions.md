# 独立于模型的执行权限

模型只提出工具名和参数。服务端在执行边界决定是否允许；提示词、工具描述、Agent profile、会话消息以及模型声称的“已获批准”都不能授予权限。

## 服务端授权范围

`SECURITY_PRINCIPAL_POLICIES` 是管理员部署配置，不接收模型参数。示例：

```dotenv
SECURITY_WORKSPACE=/srv/weaver/workspaces
SECURITY_PRINCIPAL_POLICIES={"*":{"tools":["rag_search","tavily_search","crawl_url","str_replace"]},"alice":{"workspace":"alice","tools":["rag_search","str_replace"],"network":false},"researcher":{"workspace":"researcher","domains":["docs.example.com"]}}
```

- `tools`：完整工具名的允许范围。未设置时继承全局策略；空数组拒绝全部工具。列出某个未知工具并不会让它通过基础策略。
- `workspace`：相对于部署工作区的子目录或其内部绝对目录，不能逃逸全局工作区。`str_replace` 仍须单独审批。
- `domains`：抓取 URL 的精确域名范围，与 `SECURITY_ALLOWED_DOMAINS` 取交集。空数组禁止抓取任何目标；不支持通配符。搜索供应商和 MCP 连接器的网络地址由服务配置管理，不由此抓取域名字段控制；要完全禁止外发，使用 `network:false`。
- `network`：`false` 禁止搜索、抓取和 MCP 调用，包括管理员标为只读的远程工具。

部署默认值、`*` 规则和用户规则逐层取交集。请求开始时保存不可变范围，执行时再与最新配置相交；请求中途只能缩小权限。新配置格式错误、工作区不相交或审计存储不可用时停止执行。

HTTP 身份来自认证代理提供的可信身份。生产环境必须配置内部鉴权；代理必须剥离客户端自行传入的身份头。未配置鉴权的开发环境统一使用 `local`，没有多用户隔离。Agent 的 `enabled_tools` 只控制可见工具，不能扩大服务端授权范围。

## 审批和执行许可

`SecureTool` 和强制安装的 `SecurityMiddleware` 覆盖注册工具及动态工具。直接搜索/抓取研究入口也执行出站检查。未知工具默认拒绝，宿主 Shell 不开放；关闭 `SECURITY_ENABLED` 不会恢复这些能力。

持久审批绑定用户、线程、工具调用 ID、工具定义与 MCP 服务指纹、完整参数、策略范围、风险/私有来源状态和文件内容摘要。修改参数必须重新审批。恢复时检查最新权限；撤权、文件变化、审批过期或审批已消费均不能继续原操作。

审批通过后生成当前运行的内存许可，额外绑定运行 ID。文件/MCP 的底层执行入口再校验身份、工具实现、参数和策略，并原子消费一次。换用户、会话、运行、MCP 服务或参数不能复用许可。重复调用必须走新的授权流程。

## 私有来源后的外发

记忆召回、RAG 和 MCP 返回值由服务端标记为私有来源，标记按用户和线程写入账本。该标记不依赖模型分类或提示注入规则；新的请求、摘要和审批恢复不会清除它。

同一线程一旦读取这些来源，搜索查询、抓取 URL 和后续 MCP 参数都可能携带私有信息，因此转为逐次审批。许可绑定外发查询/URL；内层研究助手修改这些内容后会被阻止。没有 LangGraph 检查点审批能力的直接研究调用保持拒绝，应改用具备审批恢复能力的 Agent 工具路径。

这是保守的线程级控制：不能自动判断任意用户输入是否保密，也不做逐字符数据血缘追踪。只读 MCP 结果也按私有数据处理，后续公开搜索可能需要多一次审批。新建独立会话可重新进行公开研究。

## 验证与边界

运行 `tests/test_execution_permissions.py` 与 `tests/test_agent_security.py`，验证扫描关闭、伪造授权、跨身份/会话/运行重放、MCP 服务替换、审批撤权、私有资料外发和直接搜索旁路。断言检查文件内容、模拟 HTTP/MCP 调用次数和真实 LangGraph 中断/恢复，不使用模型的拒绝文本作为安全证据。

本边界约束应用内工具权限，不替代进程沙箱、MCP 服务内部授权或网络防火墙。抓取域名检查不防 DNS 重绑定和重定向链路；生产出网仍需独立代理限制。`SECURITY_ENABLED=false` 仍会关闭可选模型内容防护，生产应保持开启。已控制宿主 Python 进程的代码不属于此权限模型防御范围。
