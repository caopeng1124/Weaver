# Weaver v0.7.0

发布日期：2026-10-09。整合分支：`codex/integrated-v0.7.0`；版本标签：`v0.7.0`。

## 包含的更新

| 来源 | 更新 |
| --- | --- |
| `codex/local-sandbox-security` / `b3eff16` | 移除 Web、Agent、MCP 手动入口；默认自动路由；保留 Deep Research 开关和对应后端协议。 |
| `codex/unified-context-entry` / `3355c19`、`0f6c324` | 统一可信模型上下文；工具权限独立于内容扫描，执行许可绑定用户、线程、运行、工具、参数和策略。 |
| `codex/docker-sandbox` / `4a3f2b4` | 默认 Docker 托管沙箱、会话文件、产物下载、工作区写回审批；E2B 显式可选。 |
| `codex/permission-aware-rag` / `36ccc5d` | 检索前后检查文档权限，隔离集合并验证内容完整性。 |

以上功能基于现有 Agent 安全审批分支整合。旧本地沙箱分支的初版实现由新的托管沙箱替代，界面及自动路由提交单独移入，避免恢复旧权限机制。

整合修复包括：沙箱工具使用统一的单次执行许可，关闭内容扫描也不能绕过权限；RAG 的工具与服务入口都保留私有数据标记，后续外发仍需授权；沙箱面板沿用线程归属协议，并修正配置接口地址以显示实际沙箱状态；前端与 SDK 的 OpenAPI 类型同步更新。

原工作目录中的 Python 启动版本、路由注释和前端 esbuild/锁文件配置一并保留。运行时记忆文件改为本地忽略文件；现有记忆、学习笔记和 `.env` 不作为版本发布内容。

## 启动与升级

新安装可直接使用版本标签：

```bash
git clone --branch v0.7.0 https://github.com/caopeng1124/Weaver.git
cd Weaver
cp .env.example .env
cp web/.env.local.example web/.env.local
make setup
pnpm -C web install --frozen-lockfile
```

`make setup` 默认使用 Python 3.13；已安装 Python 3.11/3.12 时可传入 `PYTHON=python3.11` 或 `PYTHON=python3.12`。已有环境保留原 `.env`，无需重新复制模板。

分别在两个终端运行：

```bash
.venv/bin/python main.py
```

```bash
pnpm -C web dev
```

界面地址 `http://localhost:3100`；后端默认 `http://localhost:8001`。`/health`、`/api/config/public` 和 OpenAPI 元数据均显示 `0.7.0`。

已有 `.env` 如果使用 `SANDBOX_MODE=local`，该值仍代表 E2B 兼容模式；使用本机沙箱请改为 `SANDBOX_MODE=docker`，启动 Docker 后运行 `make sandbox-build`、`make sandbox-doctor`。模型 API 密钥、地址和模型名称保持按原服务配置。详见 [快速开始](../getting-started.md) 和 [Docker 沙箱](../docker-sandbox.md)。
